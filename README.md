## 🛠️ Technical Competencies & Architecture
* **Data Transformation & Cleansing:** Power Query (M Language), cross-year schema appending, custom conditional groupings.
* **Analytical Modeling:** Star Schema design, disconnected metric tables, time-series benchmarks.
* **DAX Calculations:** Dynamic format strings (`/kg`), dynamic switcher measures, statistical aggregations (`AVERAGEX`, `CALCULATE`, `SELECTEDVALUE`).
* **Visualization Best Practices:** Accessible public sector themes, KPI callouts, line/clustered comparisons, drill-through workflows.
